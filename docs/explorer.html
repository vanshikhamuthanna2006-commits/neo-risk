Conformal follow-up sets

Each object gets a set of plausible labels. "Hazardous" is included unless the model is confident it is benign, with a guaranteed miss rate of at most αH among true hazards. Objects whose set contains both labels go to follow-up observation.

Coverage is guaranteed on average over calibration draws, so the realised value can sit slightly under the target. With few calibration hazards (Mode A has ~100 per fold), very small αH forces "hazardous" into every set.

The circularity trap

A potentially hazardous asteroid is defined as MOID ≤ 0.05 au and H ≤ 22. A model given MOID and H just re-derives the rule, which is why published classifiers report near-perfect scores.

This project removes MOID, H and anything that reconstructs them (albedo + diameter, Sentry outputs) behind two hard gates, a name filter and a rank-correlation check (|ρ| < 0.995 against every audit column), enforced before every model is trained.

How much is still recoverable?

A probe model tries to predict H and MOID from the features that remain. A high R² means the information is still there implicitly (MOID follows from the orbital elements; H correlates with how an object was observed). That is physics, not a leak, but it bounds what "leak-free" can mean.

Method in brief

Data
JPL SBDB (all NEOs with a full covariance), JPL Sentry list. 43,160 objects.
Targets
Mode A: PHA flag (without its defining inputs). Mode B: on the Sentry impact-risk list.
Dynamics
REBOUND N-body (Sun, Venus, Earth–Moon, Mars, Jupiter, Saturn), 50 years, MERCURIUS with IAS15 for tight perihelia: drift in a, e, i at 10/25/50 yr, minimum Earth distance, divergence/Lyapunov proxy.
Uncertainty
32 antithetic clones per object from the full JPL covariance, propagated 50 yr: spread of close-approach distance, P(dmin < 0.05 au), etc. Taxonomy-based physical priors with explicit masks, no mean imputation.
Models
LightGBM (log-loss), Platt-calibrated; Mondrian split-conformal sets. The paper also compares a focal-loss variant and a dual-branch MLP; neither beat LightGBM.
This site
5-fold out-of-fold scores for every object (train/val/cal inside each fold). Headline intervals come from the 5-seed held-out test splits in the paper.

Read these before quoting a number

  • Sentry builds its list by searching each object's covariance for virtual impactors. The clone features are a coarse version of that search, so Mode B partly measures how well a cheap model emulates Sentry.
  • 139 objects have no usable covariance; none are on either target list.
  • Covariances were downloaded up to two days after the labels.
  • This is a research classifier, not an impact-monitoring system. For real risk, use JPL Sentry and ESA NEOCC.
